# Lintree

A modern and lightweight link-in-bio platform.

Built to help creators, developers, and brands share everything from a single page with a clean and customizable experience.

---

## Overview

Lintree is a simple alternative to traditional link pages.

Create a personalized profile, organize your important links, and share one URL across all platforms.

---

## Features

- Clean and modern interface
- Responsive design
- Fast performance
- Custom profile page
- Social media links
- Easy customization
- Mobile-first experience

---

## Tech Stack

- Next.js
- React
- Tailwind CSS
- TypeScript

---

## Philosophy

Less clutter.

More focus.

One page. Every link.

---

## Getting Started

```bash
git clone https://github.com/FikriBintangx/lintree.git

cd lintree

npm install

npm run dev
```

Open:

```txt
http://localhost:3000
```
